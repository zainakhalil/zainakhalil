I’m Zaina: a Cairo-raised, Chicago-shaped **MCS student at UIUC** asking that question across language, learning sciences, and technology. I grew up listening to my grandparents’ stories move between Arabic and English; now I study what happens when people move between languages while learning something new.

## Current questions

- How do Arabic-English and Spanish-English speakers learn introductory programming with AI?
- What happens when learners use AI over time—and how can tools help them become more independent?
- How do we make AI learning materials work across languages, scripts, and classrooms?

At **PAWS Lab, University of Pittsburgh**, I’m currently evaluating 123 LLM-generated Arabic translations of Python worked examples for a planned bilingual classroom study. I flagged missing diacritics and right-to-left number-order issues that led the lab to regenerate translations.
